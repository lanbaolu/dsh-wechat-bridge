## 文案 B｜极客技术版

**标题：开源神器：把 DeepSeek 装进微信当遥控器⚡**

不是标题党，是真能把微信变成你本机 AI 的遥控器。

项目：dsh-wechat-bridge（开源）
原理一句话：微信 ← iLink Bot 协议 ← 本地守护进程 ← DSH Agent

做了啥：
🖱️ 微信扫码绑定，聊天框直连本机 Agent
🖼️ 文字 / 图片 / 语音转文字 / 文件，全通道
🔄 每账号一个持久化会话，Host 重启自动 resume，上下文不断档
⚡ SSE 流式回复 + 批量推送，不刷屏不触发限频
📎 双向文件：微信发进去，AI 回复的文件推回来
⏸️ 消息队列 + 超时安抚（5 分钟没动静自动报平安）

安全面：
🔒 内部 API 只监听 127.0.0.1 + 随机 token
🔑 账号凭证 0600 权限存本机
🧹 日志自动脱敏 token/secret

三端通用，纯 Node 进程管理，不依赖 launchd/systemd。

安装就两行：
npm install @lanbaolu/dsh-wechat-bridge
dsh plugin --profile web add @lanbaolu/dsh-wechat-bridge

⚠️ 非官方微信协议，账号风险自行评估，小号测试更稳。

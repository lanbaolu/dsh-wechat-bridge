## 定位与愿景

- 定位：唯一 agent 自己能管理的微信桥（面板 / 审批 / 防风控 / 崩不坏）。
- 愿景：把微信桥做成**个人 AI 基础设施**、微信品类第一、装上不用管；先微信后多渠道。
- 竞争文档 P0 已完成；P1/P2 未开始（本文档承接）。

## 工程原则（从历史 bug 提炼）

- 微信风控规避优先：一切对外发送都要批量 + 节流 + context_token。
- fail-closed 安全基线：发送者校验、守卫、信任集门禁只进不退。
- daemon/插件生命周期竞态：await 后访问引用必须防 undefined（0.7.1 教训）。
- 发布 SOP：TP 发布（tag 触发 CI）+ 发布前真机闭环 + 每次单独确认。
